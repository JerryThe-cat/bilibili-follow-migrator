# B站关注迁移助手（A → B）

将自己 A 账号的 UP 主关注名单复制到自己 B 账号的 Tampermonkey 用户脚本。不需要桌面客户端。

## 功能

- 完整读取 A 的关注名单，检查分页及人数后导出 JSON。
- 在 B 账号中导入并比对，跳过已有关注及 B 自己。
- 默认每次关注间隔 8–10 秒；基础间隔可设置为 5–120 秒。
- 每次操作前检查账号；逐条保存进度，支持暂停、刷新后继续。
- 支持手动重试失败项；网络异常、风控及连续失败会停止本轮。
- 迁移后重新读取 B 的关注名单核对，支持导出完整进度报告。

只新增关注，不取消 A/B 的关注，不迁移分组、关注时间或老粉身份。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 打开 **[在线安装助手](https://jerrythe-cat.github.io/bilibili-follow-migrator/)**，点击“复制完整脚本”，按页面步骤安装。
3. 也可点击 **[直接安装脚本](https://jerrythe-cat.github.io/bilibili-follow-migrator/bilibili-follow-migrator.user.js)**；如果浏览器没有弹出油猴安装界面，请使用在线安装助手复制安装。
4. 刷新 [B站首页](https://www.bilibili.com/)，点击右下角“关注迁移 A → B”。

脚本仅在 `www.bilibili.com` 运行，空间页面 `space.bilibili.com` 不显示入口。若没有入口，请在扩展详情中开启“允许用户脚本”，参阅 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。

也可下载仓库 ZIP 并解压，打开 `安装助手.html`，点击“复制完整脚本”。

## 使用

1. 登录 A 并刷新首页，识别账号后点击“读取并导出 A 的全部关注”。
2. 登录 B 并刷新首页，选择 A 导出的 JSON，点击“比对 B，生成待迁移名单”。
3. 检查 A/B 的 UID 与待迁移人数，点击“开始 / 继续”，确认后开始。
4. 需要停止时点击“暂停”；稍后在同一浏览器中登录 B，点击“开始 / 继续”，无需再次导入。
5. 通过“重试失败项”和“核对迁移结果”处理未完成的关注。

进度存储在当前浏览器的脚本存储中，关闭页面后不会自动继续。更换浏览器或删除扩展数据后，可以重新导入 A 的原始名单并比对恢复任务。不要在运行过程中切换登录账号。

完整说明见 [使用说明.txt](使用说明.txt)。

## 数据与限制

- 脚本仅请求 `api.bilibili.com`，不包含外部运行依赖或统计服务。
- 导出的名单和进度报告不含 Cookie；不要将自己的名单、报告或登录凭据提交到仓库。
- 限速无法保证不会触发平台限制；遇到限制后应等待恢复再手动续传。
- B站接口可能变化。当前已进行模拟测试，尚未使用真实账号完成联调。
